# 瞬悉全宇宙 · 启动文档

从零把项目跑起来的完整步骤，以及常用命令和排错。

## 1. 前置要求

- Node.js >= 20（当前环境 v20.18.2）
- npm >= 10（当前环境 10.8.2）

本仓库使用 **npm workspaces** 管理 monorepo（根目录 `package.json` 的 `workspaces` 字段）。
> 仓库里遗留了一份 `pnpm-workspace.yaml`，但没有安装 pnpm，实际以 npm 为准，不要混用。

## 2. 安装依赖

在仓库根目录执行：

```bash
npm install
```

依赖会统一装到根目录 `node_modules`，`apps/web`、`apps/api`、`packages/contracts` 之间通过 workspace 自动链接。

## 3. 环境变量

复制示例文件生成 `.env`（放在仓库根目录）：

```bash
cp .env.example .env
```

说明：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8787` | 后端 API 端口 |
| `VITE_API_BASE_URL` | `/api` | 前端请求后端的基础路径 |
| `ZHIHU_API_KEY` | 空 | 知乎官方 API Key（后端使用） |
| `AI_API_KEY` | 空 | AI 模型密钥（后端使用） |

> 密钥只在后端使用，前端通过 `/api` 代理访问，不会直接暴露。Demo 阶段后端内置了 mock provider，不填密钥也能跑通。

## 4. 启动

前端和后端两个进程，分别在两个终端里执行：

```bash
# 终端 1：后端 API
npm run dev:api

# 终端 2：前端 Web
npm run dev:web
```

也可以直接进到子包目录单独启动：

```bash
npm --workspace apps/api run dev
npm --workspace apps/web run dev
```

## 5. 访问地址

| 服务 | 地址 |
| --- | --- |
| 前端页面 | http://localhost:5173 |
| 后端健康检查 | http://localhost:8787/health |
| 探索 API | http://localhost:8787/api/v1/explorations |

Vite 已在开发环境把 `/api` 请求代理到 `http://localhost:8787`，所以前端代码里直接用相对路径 `/api` 即可。

## 6. 常用命令

在仓库根目录执行：

```bash
npm run dev:web      # 启动前端（Vite）
npm run dev:api      # 启动后端（Hono + tsx watch）
npm run typecheck    # 全仓库 TypeScript 类型检查
npm run build        # 全仓库构建
npm run test         # 全仓库测试（目前覆盖 api 的 providers）
```

## 7. 目录结构

```
curioverse/
├── apps/
│   ├── web/          # 前端：页面、交互、响应式布局、API Client
│   └── api/          # 后端：REST API、探索流程编排、知乎/AI Provider、缓存
├── packages/
│   └── contracts/    # 前后端共用的 Zod Schema 和 TS 类型
├── fixtures/         # 本地开发与演示的备用数据
└── docs/             # 文档
```

- `apps/web` 不直接调用知乎接口，只依赖 `@curioverse/contracts` 和 `apps/web/src/api/client.ts`。
- `apps/api` 通过 `providers/` 隔离知乎和 AI 实现，路由层不直接写第三方调用。

## 8. 常见问题

**端口被占用**
前端默认 5173、后端默认 8787。改端口：后端改 `.env` 的 `PORT`，前端改 `apps/web/vite.config.ts` 里的 `server.port`，同时记得同步 `proxy` 指向的后端地址。

**前端请求后端报 404 / 502**
确认后端进程已启动，且 `.env` 里 `VITE_API_BASE_URL=/api`、Vite 代理指向的后端端口与 `.env` 的 `PORT` 一致。

**改了 contracts 后类型报错**
先改 `packages/contracts` 的 Schema，再分别同步前后端；工作区链接的是源码，直接 `npm run typecheck` 即可验证。
